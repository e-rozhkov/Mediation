# Редактирование материалов

JSON из `src/content` автоматически подключаются к статической сборке. Изменения публикуются через новую сборку; админки и серверного редактора нет.

## Иллюстрации

Добавьте файл в `public/images` и укажите `image: {"src":"/images/example.webp","alt":"Описание изображения","width":1536,"height":1024}`. Используйте фактические размеры: у баннеров из нового документа пропорция 3:1. Русский учебный текст должен оставаться в HTML, а не только в картинке. Сборка проверяет наличие файла.

## Уроки и курс

Урок содержит `id`, `slug`, `version`, `module`, `order`, `blocks`, `sections`, `adult_note`, `question`, `choices`, `scenario` и поля общего материала. В `blocks` находятся краткие мысли, в соответствующих `sections` – заголовок и полный текст. Их количество должно совпадать. Оглавление и переходы с прокруткой строятся автоматически. В одном вопросе три ответа, один верный; пояснения есть у всех ответов.

Файл курса задаёт порядок уроков и массив `questions` для итоговой самопроверки. Его длина не зафиксирована в интерфейсе. После существенной правки увеличьте `version` урока или курса, чтобы старое прохождение не выдавалось за новое.

## Структурированные блоки

Страница о медиации и памятки используют единый набор блоков:

- `paragraph`, `note`, `heading`: поле `text`.
- `table`: массив `headers` и массив строк `rows`. Число ячеек каждой строки должно совпадать с числом заголовков. Ячейки из подчёркиваний отображаются как место для записи.
- `steps`: массив `items` с `title` и `text`; упорядоченная схема.
- `branches`: `title` и варианты с `title`, `text`, `result`.
- `faq`: вопросы и ответы в `items`.
- `writing`: `label` и `prompts`; строки для заполнения на распечатке, без сбора персональных заметок в браузере.

Материалы имеют уникальные `id` и `slug`, имя файла совпадает со slug. Роли `audience` применяются только для контекста и не фильтруют каталог. Возрастные поля не используются. Общие тексты медиации и помощи хранятся в одном файле `pages/mediation.json`; у разделов уникальные `id`.

## Памятки и PDF

У памятки есть `order`, `topic`, `intro`, `image`, `content` и `pdf`. Команда `python scripts/generate-pdf.py` создаёт PDF из тех же данных. PDF и картинки нужно сохранить в Git. Проверяйте рендер всех страниц: наличие текста, правильный перенос ячеек, читаемую кириллицу, отсутствие обрезки. Старые PDF-имена автоматически получают копии новых документов по таблице алиасов в генераторе.

Старые URL материалов описаны в `src/lib/aliases.ts`; ссылки из кейсов и уроков должны вести на действующие canonical slug. Проверка алиасов выполняется перед сборкой.

## Команды проверки

`npm run validate:content`, `npm run build`, `npm test`, `npm run test:e2e`. После изменения печатных материалов сначала пересоздайте PDF. Общая тема – `src/styles/theme.css`, остальные стили – `src/styles/app.css`. Шрифт Manrope и его лицензия находятся в `public/fonts/`.
