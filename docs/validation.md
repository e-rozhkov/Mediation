## Оставшиеся ограничения

Материалы — учебные черновики, требуют проверки педагогом перед реальным обучением. Контакты конкретной школы не согласованы, реальных обращений сайт не принимает. Кабинет редактора не реализован; картинки и тексты меняются через файлы по docs/content-editing.md. Полный аудит доступности, проверка всех экранов при масштабировании и проверка опубликованной версии остаются отдельными шагами. Итоговый отчёт полного проекта из первоначального плана не подготовлен в этой итерации.
