# Точка диалога

Учебный демонстрационный сайт о школьной медиации для детей **7–10 лет**, родителей и учителей, по [плану](docs/plan.md). React + TypeScript + Vite, статическая сборка без серверной части.

Сейчас доступны:

- четыре модуля, восемь коротких уроков и по три вопроса с пояснениями в каждом модуле;
- пять четырёхшаговых кейсов с последствиями выбора, восстановлением попытки и итогами;
- восемь памяток с поиском, фильтрами по аудитории и теме, чеклистами, печатью A4 и PDF;
- семь иллюстраций, включая два изображения из предоставленного документа;
- разделы о медиации, помощи и проекте, страница 404.

Материалы для взрослых обозначены отдельно. Кейс «Разные ожидания» не входит в детскую подборку. Перед реальным обучением тексты должен проверить педагог. Реальных обращений сайт не принимает, школьные контакты ещё не согласованы.

## Запуск

Node.js **24.19.0** (см. `.nvmrc`), npm **11.9.0**. Версии пакетов зафиксированы в package-lock.json.

```sh
cd /workspace/Mediation
npm ci --cache /workspace/.npm
npm run dev
```

На своём компьютере используйте путь к распакованной папке и обычное `npm ci`.

Команды: `npm run typecheck`, `npm run validate:content`, `npm test`, `npm run build`, `npm run test:e2e`, `npm run preview`.
E2E использует установленный `/usr/bin/chromium`. Другой исполняемый файл задаётся через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Preview запускается и останавливается Playwright автоматически на порту 4173; предварительно нужна сборка.

## Материалы и картинки

JSON находятся в `src/content/{modules,lessons,scenarios,resources}`. Каталог автоматически подхватывает JSON из этих папок. Схемы – `src/lib/schemas.ts`, проверка связей и файлов – `scripts/validate-content.ts`. Общий игровой экран не содержит реплик.

Иллюстрации – `public/images/*.webp` (весь набор около 800 КБ). Поле `image` в JSON задаёт путь и текстовое описание. Как заменить или добавить изображение – [инструкция редактору](docs/content-editing.md). Админки пока нет: изменения материалов сохраняются в Git и публикуются новой сборкой.

Прогресс схемы v2 раздельно сохраняет версии пройденных уроков, лучшие результаты вопросов по модулям, попытки каждого кейса и выбранную реплику до перехода. Старый формат первой итерации переносится автоматически. При недоступном localStorage используется память страницы с предупреждением. Очистка браузера удаляет прогресс; сброс на сайте требует подтверждения. Регистрации, API, аналитики и сбора персональных данных нет.

Тема – `src/styles/theme.css`. Стили печати A4 – `src/styles/app.css`. Готовые PDF включены в `public/pdf/`; для изменения используйте `python scripts/generate-pdf.py` (ReportLab; Manrope включён в `public/fonts/`), затем проверьте каждую страницу после рендеринга. Приложению Python не нужен.

## Размещение

Раздавать `dist/` через HTTPS. Для Netlify добавлены `public/_redirects` и `404.html`: маршруты приложения возвращают index.html, отсутствующие `/pdf/*`, `/images/*`, `/assets/*` – 404. Для другого хостинга настройте аналогичные правила. Не использовать `vite preview` как production-сервер.

Перед выпуском проверить прямые ссылки после обновления, отсутствие подмены файлов HTML и кэширование: index.html должен перепроверяться при новой публикации; хешированные assets допускают длительный immutable cache. Отправка кода в GitHub сама по себе не подтверждает обновление опубликованного сайта.

Результаты проверок – [docs/validation.md](docs/validation.md). Дальнейшие задачи: педагогическая проверка, реальные согласованные контакты перед применением в школе, проверка опубликованной версии и отдельное проектирование кабинета редактора, если он потребуется.


## Изменения по документу от 1 ноября 2026

На главной и странице «О медиации» добавлены полное объяснение, таблица аудиторий, роли, принципы, границы конфиденциальности, восстановительный подход и схема встречи. Тексты находятся в `src/content/pages/mediation.json`. На внутренних страницах есть хлебные крошки с переходом «Главная». Декоративные номера разделов убраны; полезная нумерация уроков и шагов сохранена.

Первый урок «Замечаем конфликт» содержит 14 тем с короткими пояснениями и полными подробностями из документа. Старый адрес сохранён, версия урока и первого теста повышена: результаты прежнего содержания не считаются прохождением нового.

С согласия пользователя вместо Circe используется бесплатный **Manrope**, включая кириллицу, интерфейс и PDF. Веб-шрифт размещён локально, обращения к Google Fonts при открытии сайта нет. Лицензия SIL OFL 1.1 включена в `public/fonts/OFL-Manrope.txt`. Источник: [google/fonts, Manrope](https://github.com/google/fonts/tree/main/ofl/manrope). Файл Regular для PDF получен из официального variable-шрифта при wght=400 через fontTools. Для тире используется средний знак «–».
