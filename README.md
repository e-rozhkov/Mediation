# Точка диалога

Учебный статический сайт о школьной медиации для всех, кто хочет учиться договариваться. React + TypeScript + Vite. Текущие материалы перенесены из документа «Медиация сайт (1) (1).docx» от 21 ноября 2026 года.

- Полный раздел о медиации: цели, роли, принципы, восстановительный подход, ситуации для обращения, отличие ссоры от травли, подготовка, правила встречи и ответы на частые вопросы.
- Шесть последовательных уроков и общая самопроверка из шести вопросов с пояснениями.
- Пять игровых ситуаций с последствиями выбора и восстановлением прогресса.
- Шесть памяток с таблицами, схемами, местом для записей, печатью и PDF A4.
- Развёрнутая страница помощи, общие каталоги, поиск и темы без возрастных фильтров.

Сохранены Manrope, средние тире, закреплённое меню, ссылка «Главная», автоматическая прокрутка к теме урока и отсутствие декоративных подзаголовков. Материалы требуют проверки педагогом перед реальным применением. Сайт не принимает обращения; реальные контакты школы не предоставлены.

## Запуск

Node.js **24.19.0**, npm **11.9.0**; версии зависимостей зафиксированы в package-lock.json.

```sh
cd /workspace/Mediation
npm ci --cache /workspace/.npm
npm run dev
```

На своём компьютере используйте путь к проекту и `npm ci` без параметра cache.

Проверки: `npm run typecheck`, `npm run validate:content`, `npm test`, `npm run build`, `npm run test:e2e`. E2E запускает preview на 4173 и использует `/usr/bin/chromium`; другой бинарник задаётся через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Перед E2E нужна актуальная сборка.

## Как менять содержание

- `src/content/pages/mediation.json`: общий источник текстов раздела медиации и выбранных разделов помощи.
- `src/content/lessons/`: один JSON на урок; краткие блоки, полные пояснения, упражнение и вопрос. Все абзацы шести уроков сверены с исходным документом.
- `src/content/modules/`: курс, порядок уроков и итоговая самопроверка. Число вопросов не зафиксировано в компоненте.
- `src/content/resources/`: один JSON на памятку; структурированные абзацы, таблицы, схемы и поля для распечатки.
- `src/content/scenarios/`: пять прежних кейсов, их рекомендации ссылаются на новую библиотеку.

Общий renderer `src/components/ContentBlocks.tsx` показывает таблицы и схемы как доступный HTML, без текста внутри растровых схем. `scripts/validate-content.ts` проверяет структуры, переходы, ссылки, файлы, одинаковое число ячеек в строках и уникальные идентификаторы разделов. Метаданные ролей не ограничивают доступ.

В `public/images/document21-*.webp` находятся 13 иллюстраций из нового документа. Поля width/height сохраняют исходные пропорции, включая широкие баннеры. Схемы из документа воспроизведены версткой, чтобы они читались на телефоне и при увеличении текста.

Готовые PDF находятся в `public/pdf/`. Пересоздать: `python scripts/generate-pdf.py` (ReportLab и Pillow). Генератор читает те же материалы и изображения, что интерфейс, и использует локальный Manrope. Строки личных заметок заполняются на распечатке; приложение не собирает свободный ввод. После изменения памяток проверяйте каждую страницу PDF и HTML-печать на A4.

## Совместимость и прогресс

Старые адреса уроков, модулей и памяток разрешаются через `src/lib/aliases.ts`. Старые PDF-адреса сохраняют актуальную копию подходящей новой памятки. Не удаляйте алиасы без проверки существующих ссылок.

Версии изменённых уроков и теста повышены, чтобы предыдущая отметка не считалась прохождением нового материала. Прогресс остальных материалов и игровые попытки остаются в браузере. Повреждённые записи и недоступное хранилище обрабатываются; сброс требует подтверждения. Очистка браузера удаляет результаты. Регистрации, аналитики, API и сбора персональных данных нет.

## Размещение

`npm run build` создаёт `dist/`. В Netlify: ветка `main`, команда `npm run build`, publish directory `dist`. `public/_redirects` оставляет SPA fallback для страниц и ошибку для отсутствующих PDF, картинок, шрифтов и assets. Для другого хостинга нужны аналогичные правила.

Используется локальный Manrope по ранее согласованной замене Circe, лицензия SIL OFL 1.1 включена в `public/fonts/OFL-Manrope.txt`. Runtime не обращается к Google Fonts. Коммерческий Circe без предоставленного веб-набора не добавлялся.

Публикация в GitHub не подтверждает обновление Netlify. Проверку опубликованной версии можно выполнить после получения её адреса. Результаты проверок: [docs/validation.md](docs/validation.md). Первоначальный план сохранён как архив в docs/plan.md и не описывает текущие количества материалов.
