# Точка диалога

Учебный демонстрационный сайт о школьной медиации для детей 7–10 лет и взрослых. Первая итерация по [плану](docs/plan.md): главная, один урок, четырёхшаговый кейс «Общее задание», одна памятка с PDF, страницы помощи и проекта. Остальные уроки и кейсы ещё не реализованы. Перед реальным обучением тексты должен проверить педагог.

## Запуск

Node.js **24.19.0** (см. `.nvmrc`), npm **11.9.0**. Версии пакетов зафиксированы в package-lock.json.

```sh
cd /workspace/Mediation
npm ci --cache /workspace/.npm
npm run dev
```

Команды: `npm run typecheck`, `npm run validate:content`, `npm test`, `npm run build`, `npm run test:e2e`, `npm run preview`.
E2E использует установленный `/usr/bin/chromium`. Другой исполняемый файл задаётся через `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Сервис проверки preview запускается и останавливается Playwright автоматически на порту 4173; предварительно нужна сборка.

## Материалы

JSON находятся в `src/content/{lessons,scenarios,resources}`. Схемы и граф переходов — `src/lib/content.ts`; CLI-валидация — `scripts/validate-content.ts`. Общий игровой экран не содержит реплик. Итог хранит фактические ответы. Прогресс имеет версию схемы и кейса, сохраняется локально с резервной работой в памяти. Сброс требует подтверждения. Регистрации, API, аналитики и приёма обращений нет.

Тема — `src/styles/theme.css`. Стили печати A4 — `src/styles/app.css`. PDF уже включён в `public/pdf/`; для изменения используйте `python scripts/generate-pdf.py` (ReportLab и системный DejaVu Sans), проверьте рендер каждой страницы. Приложению Python не нужен.

## Размещение

Раздавать `dist/` через HTTPS. Хостинг пока не выбран, сайт не опубликован. Возвращать index.html для маршрутов приложения, но **404 для отсутствующих `/pdf/*`, `/images/*`, `/assets/*`**. Не использовать `vite preview` как production-сервер. Перед выпуском проверить вложенные ссылки после обновления и отсутствие подмены файлов HTML. index.html должен перепроверяться при новой публикации; хешированные assets допускают длительный immutable cache.

Нужны дальнейшие этапы: 4 модуля по 2 урока с тестами, ещё 4 кейса, ещё 7 памяток, педагогическая проверка содержания, согласованные контакты для реального использования и публикация. См. полный план и [результаты проверок](docs/validation.md).
